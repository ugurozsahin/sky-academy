# Sky Ninja Academy

Slice-the-answer maths & writing game for Reception, Year 1 and Year 2 (England: EYFS + KS1 National Curriculum). Mobile-first, works on desktop.

```
npm install
npm run dev        # http://localhost:5173  (use the Network URL on your phone)
npm test           # unit tests (question generators, session logic)
npm run test:e2e   # Playwright: real play-throughs on mobile + desktop viewports
npm run build      # dist/
node scripts/bundle-single.mjs   # one self-contained HTML file
```

See `CLAUDE.md` (project context), `docs/CURRICULUM.md` (curriculum map); the backlog is the GitHub issue list, ordered by its `priority:*` labels.
