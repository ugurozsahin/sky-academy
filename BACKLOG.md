- **Order**: issue **#46 "📌 Priority order (owner-maintained)"** is the single ordered list. The owner reorders it; Claude works top-down.
- **Labels**: `priority:P1/P2/P3`, `owner-input` (needs the owner's art/decision), `routine-ok` (the dev routine may take it), `owner-approval` (on a PR: blocks the merge until the owner writes `OWNER: APPROVED`; only for a genuinely new look), `later` (parked), plus area labels (`mode`, `curriculum`, `art`, `reward`, `platform`, `playtest`, `review`, `perf`, `debt`, `tests`).

- **Freeze (owner, 2026-09-06):** no new feature work while any issue labelled `review` or `debt` is open. Still allowed: finishing open PRs, `playtest` bugs, anything that makes the game unplayable or `main` red, and whatever the owner asks for in a session. See the two sections in #46. (Same wording in CLAUDE.md and docs/ROUTINE-PROMPT.md — change all three together.)
- **Guard rails**: `tests/unit/guardrails.test.ts` and the `guard rail:` e2e tests turn past incidents into failing checks. Budgets go down, never up.
- **Workflow** (minimum scrum, in every issue): Refine → Develop (agent A, branch `claude/issue-<n>` or the run's assigned push branch, PR titled `(#<n>)` with `Closes #<n>` in the body — `Part of #<n>` instead when part of the issue is deferred, or GitHub closes it early. **A closing keyword next to an issue reference closes that issue wherever it sits in the body — including inside a sentence denying it (#144).** "Left open so merging this does not close #<n>" is how PR #139 shut issue 44 while explaining that it must not: GitHub scans the whole body for `close`/`fix`/`resolve` and their forms followed by `#<n>` or the issue's URL, and has no notion of negation, quotation or context. Say "the issue stays open" instead; break the link (`#&#8203;<n>`, or "issue 44" in words) when the keyword is unavoidable; and check what you actually wrote with `node scripts/review-gate.mjs body.md`, which prints the issues that body would close.) → Review (a *different* agent) → QA (the reviewer, e2e + screenshots — **mobile by default, the project CI runs on a PR; the full matrix is the nightly's**, #141) → Owner action → Done (merged, issue closed). Merging no longer reaches the live artifact: the publisher task was stood down on 2026-09-09 and nothing republishes in its place.
