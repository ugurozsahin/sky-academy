Support

Something not working, or a question about Sharpwise? Email support@sharpwise.co.uk.

It helps to tell us the device and browser you use, and what you were doing when the problem happened. Please do not send your child's save code unless we ask for it.

Move a save to another device

Progress is kept on the device, not in an account, so it moves as a save code that you copy across yourself.

  1. On the old device, tap For grown-ups at the bottom of the Sky Map and answer the quick grown-ups' question.
  2. Scroll to Move to another device and tap Copy the code. If the browser will not copy it, select the code and copy it by hand.
  3. Send the code to yourself on the new device, for example in a message or an email to yourself.
  4. On the new device, open For grown-ups in the same way, paste the code into the box under Copy the code, and tap Restore. Tap it a second time to confirm: restoring replaces the progress on that device.

A code carries one ninja's progress: the ninja playing at the time. To move a brother's or sister's progress too, choose them with Who is playing? on the Sky Map and copy their code as well.

On Android, uninstalling the app removes its save from the device, so copy the code before you reinstall. If the device's backup is on, Android may put the save back by itself when the app is installed again. If the game says a code is not a Sharpwise save, check the whole code was pasted, and that the new device has the latest version of the game.

Start again

  1. Tap For grown-ups on the Sky Map and answer the quick grown-ups' question.
  2. At the bottom of the page, tap Start again.
  3. Type RESET in the box and tap Start again once more.

This clears the progress, stars, coins, stickers, streak, name and ninja of the child playing now. Until you leave that screen you can still tap Undo; after that it is gone.

To take one child's ninja off a shared device, tap Remove beside their name in the grown-ups' area. To clear everything Sharpwise keeps, clear this site's data in your browser's settings, or uninstall the app. On Android, a copy may also sit in the device's Google backup; the privacy policy explains it.
