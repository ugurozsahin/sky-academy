A parents' guide to Sharpwise

The questions most parents have in the first week: how to put Sharpwise on a phone, tablet or computer like an app, what the grown-ups' area does, and how to move a child's progress to another device.

Words in quotation marks, such as For grown-ups, appear exactly like that in the game.

Install it like an app

Sharpwise plays in the web browser at sharpwise.co.uk/play, so there is nothing you have to download. You can also add it to the home screen, where it gets its own icon and opens full screen, like an app.

Do this from the game page, sharpwise.co.uk/play, rather than from this website: the game is the part that installs. Browsers rename their menus from time to time, so if yours look different, look for Install or Add to Home Screen in the browser's menu.

iPhone and iPad (Safari)

  1. Open the game in Safari.
  2. Tap the Share button. On some layouts it sits behind the More button (three dots) first.
  3. On iPhone, scroll down and tap Add to Home Screen; if it is not in the list, tap Edit Actions at the bottom and add it. On iPad, tap View More, then Add to Home Screen.
  4. If you see Open as Web App, turn it on. Then tap Add.

Android (Chrome)

  1. Open the game in Chrome.
  2. Tap the menu (three dots) beside the address bar.
  3. Tap Install and create shortcut, then Install. Older versions of Chrome call it Add to home screen.

A computer (Chrome or Edge)

  1. Open the game in Chrome or Microsoft Edge.
  2. In Chrome, click the install icon at the right-hand end of the address bar. If there is none, open the menu (three dots), then Cast, save and share, then Install page as app.
  3. In Edge, accept the offer to install if one appears. Otherwise open Settings and more (three dots), then More tools, Apps and Install this site as an app.

Playing offline

Once the game has loaded over the internet, it keeps a copy on the device and plays without a connection: on a journey, or where the Wi-Fi is weak. This works whether or not you installed it on the home screen.

Progress is saved on the device, never online, so nothing is lost while you are offline. When the game is next opened with a connection, it can pick up a newer version by itself.

The grown-ups' area

At the bottom of the Sky Map, tap For grown-ups. The game asks a multiplication question, such as 7 × 8, or a bigger one written in words. Type the answer and tap Enter. It is a quick check to keep the area away from young children, not a password.

Inside, the Grown-ups dashboard shows how your child is getting on: questions answered, accuracy, stars earned and topics tried, this week's play, progress on each island, the trickiest topics and what is going well.

Everything on the dashboard is read from the device. Nothing is uploaded, and there is no account to make.

A ninja for each child

Up to four children can share one device, each with their own ninja and their own progress, coins and certificates.

A child adds their own: at the bottom of the Sky Map, tap Who is playing?, then the New ninja card. Once there are two or more ninjas, the game opens on Who is playing? so each child picks theirs.

Renaming and removing are in the grown-ups' area, under Ninjas on this device. Type a new name and tap Save name, or tap Remove and confirm. Removing a ninja clears everything saved for them and cannot be undone. The last ninja on a device cannot be removed; starting again is the way to clear it.

For a friend who is visiting, Play as a guest in the grown-ups' area lets them play without a ninja. Nothing a guest does is saved, and your children's ninjas are left alone.

Moving a save to another device

Progress lives on the device, not in an account. Removing the app or clearing the browser's data can clear it, so copy the save code first. The same code moves a child's progress to a new phone or tablet.

  1. Open the grown-ups' area while the child whose progress you want to move is playing. In Move to another device, tap Copy the code. If the browser will not copy it, select the code and copy it by hand.
  2. Get the code to the other device in any way you like, for example in a message to yourself. It holds your child's progress and ninja name, so keep it in the family.
  3. On the other device, open the grown-ups' area, paste the code into the box that says Paste a code here to restore and tap Restore. Tap Restore again to confirm.

Restoring replaces the progress of the ninja who is playing on that device with the progress in the code.

Starting again

At the bottom of the grown-ups' area, Start again clears the ninja who is playing: their progress, stars, coins, stickers, streak, name and chosen ninja. Other ninjas on the device keep theirs.

So that it cannot happen by accident, you type RESET and then tap Start again. Until you leave that screen, Undo brings everything back. After that it is gone.

Settings, including 3-D pictures

The grown-ups' area has a Settings section. Its first row is about 3-D pictures: Some shapes can be drawn as solid 3-D models. It has three buttons, and the choice applies to the whole device.

Auto
The usual choice. 3-D pictures are shown when the device can manage them.
On
3-D pictures are shown on any device that can draw them at all.
Off
Every picture stays flat. Worth trying if an older tablet feels slow.

The same section can fly the bubbles more slowly for a child who needs longer to slice, give extra time or no time limit in timed games, suggest a break after 10, 20 or 30 minutes, calm the animations, space out the words on the question card, and set the child's school year.

Ninja Duel: two players, one device

On any island, choose Ninja Duel, then a topic, or Random. The screen splits in two, one half for each player, and both get the same question. The first correct slice wins the round, and a wrong slice costs nothing. A match is ten rounds.

For a class or a family game, tap Class teams: Off before choosing the topic, so that it says On, and the two sides become Team A and Team B.

Coins from a duel go to the ninja who is playing, and the result is kept under Recent duels on the rewards screen, which opens from the coins at the top of the Sky Map.
